# 🌿 MindMate AI (마음 친구)
> **“AI가 당신의 지친 마음에 건네는 따뜻한 위로와 맞춤형 감정 음악 처방전”**

---

## 1. 서비스 명
* **서비스 국/영문 명칭**: MindMate AI : 마음 친구 (MindMate)
* **초기 프로토타입 명칭**: 감정 친구 (Emotion Friend : 마음 처방기)
* **슬로건**: “AI가 당신의 복잡한 감정을 정성스러운 한 편의 힐링 처방전과 음악으로 조율한다.”

---

## 2. 서비스 정의
* **정의**: 사용자가 겪고 있는 일상의 고민, 스트레스, 현재의 감정 상태를 텍스트로 털어놓으면, AI가 단순 조언을 넘어 **“공감 기반의 맞춤형 감정 분석 리포트와 힐링 플레이리스트”**를 처방해주는 감성 멘탈케어 플랫폼
* **핵심 지향점**: 형식적인 챗봇 대화를 넘어 **“감정의 응어리를 언어화하고, 실시간 음악 테라피와 함께 안전하게 아카이빙해주는 힐링 엔진”**

---

## 3. 기획 배경 (문제 인식)
* **감정 해소 창구의 부재**: 현대인들이 일상에서 느끼는 번아웃, 우울감, 불안을 편안하게 털어놓을 안전한 정서적 안식처가 부족함
* **개인화된 감성 케어의 한계**: 텍스트 위로만으로는 감정 회복에 한계가 있으며, 상황과 기분에 딱 맞는 음악을 일일이 검색해 찾아 듣기 번거로움
* 🔥 **핵심 문제**: *“마음을 온전히 털어놓을 곳이 없고, 내 감정 상태에 딱 맞는 따뜻한 위로와 음악을 즉각 처방받을 도구가 없는 상태”*

---

## 4. 서비스 발전 과정 (초기 MVP ➔ 최종 MindMate Editorial 버전)
실제 사용자 피드백과 모듈형 아키텍처 확장을 고려하여 2단계 이터레이션(Iteration)을 거쳐 프로덕트를 완성했습니다.

```plaintext
[Phase 1. 초기 MVP : 단순 챗봇] ────► [Phase 2. 최종 확장 : MindMate AI]
· 타깃: 단순 텍스트 상담 희망자        · 타깃: 감정 정리가 필요한 2030 및 정서적 힐링을 찾는 전 연령층
· 톤앤매너: 단조로운 기본 테마         · 톤앤매너: 편안한 파스텔 포레스트 그린 & 코지 무드
· 산출물: 단순 텍스트 답변             · 산출물: '감정 처방전 + 실시간 음악 플레이리스트 연동'
· 단일 스크립트 구조                   · 모듈화 아키텍처: UI / Storage / Music / API 분리 구조
```

* **초기 프로토타입 단계 (Phase 1 - MVP)**:
  * **핵심 기능**: 고민 입력 시 AI가 공감 멘트를 제공하고 기본 내역을 저장하는 대화형 구조 검증
  * **한계점 발견**: 텍스트 응답에만 의존하여 시각적·청각적 힐링 효과가 부족하고, 자바스크립트 코드가 단일 파일에 뭉쳐 있어 확장성이 떨어짐
* **최종 고도화 단계 (Phase 2 - Modular Mental Care System)**:
  * **감성 힐링 룩앤필 구축**: 마음의 긴장을 완화해 주는 차분한 그린/어스 톤 테마와 깔끔한 모듈형 CSS 도입
  * **음악 테라피 연동 & 모듈 분리**: 감정 분석에 맞춘 유튜브 플레이리스트(`music.js`), 로컬 영구 보관(`storage.js`), UI 분기(`ui.js`)로 전면 리팩토링 및 Discord Webhook 모니터링 연동

---

## 5. 해결 전략 (3단 구조화)
* **5.1 심층 감정 공감 엔진**: 사용자의 발화에서 지배적인 감정 키워드와 기저의 스트레스 요인을 AI가 정밀 분석하여 다정한 온도의 위로문 도출
* **5.2 멀티모달 힐링 처방**: 따뜻한 텍스트 피드백 ➔ 마음 안정 가이드 ➔ 유튜브 실시간 힐링 음원/플레이리스트 링크로 이어지는 통합 테라피 제공
* **5.3 안전한 감정 다이어리**: 처방받은 감정 기록과 음악을 외부 유출 걱정 없이 브라우저 로컬 저장소(`LocalStorage`)에 날짜별로 보관하고 회고

---

## 6. 주요 기능 상세 명세
* **6.1 감정 분석 및 맞춤 처방 (Consulting)**: 고민 입력 시 비동기 AI 감정 진단 및 따뜻한 심리 처방전 즉시 발행
* **6.2 실시간 힐링 음악 큐레이션 (Music Tab)**: 감정 상태(우울, 지침, 불안, 기쁨 등)에 최적화된 유튜브 힐링 음원 및 테마 플레이리스트 다이렉트 연동
* **6.3 마음 보관함 (Emotion Storage)**: 나만의 감정 변화 기록과 처방 내역을 로컬 서가에 안전하게 아카이빙
* **6.4 운영 알림 연동**: 사용자 상담 세션 발생 시 Discord Webhook을 통한 실시간 운영 상태 모니터링
* **6.5 실패 및 예외 처리 UX**:
  * **빈 입력(Validation)**: 내용 미입력 시 다정한 안내 알림을 띄우고 불필요한 API 호출 방지
  * **로딩 피드백**: 분석 중 "마음 친구가 당신의 이야기를 경청하고 있습니다..." 애니메이션 제공
  * **네트워크 에러 대응**: 서버 지연이나 통신 장애 발생 시 안정적인 Fallback 안내문 노출

## 7. 타겟 사용자 및 니즈 분석
* **주 타깃**: 바쁜 일상 속 스트레스와 감정 소진을 겪는 2030 세대, 혼자만의 힐링 시간이 필요한 사용자
* **부 타깃**: 일기 작성과 음악 감상을 통해 감정을 정리하고 싶은 기록형 유저
* **사용자 니즈**:
  * 타인의 시선 걱정 없이 솔직한 감정을 털어놓고 무조건적인 공감을 받고 싶은 욕구
  * 내 기분에 어울리는 음악을 직접 찾는 수고 없이 즉시 추천받고 싶은 욕구

## 9. 기술 아키텍처 및 디렉터리 구조

### 9.1 시스템 기술 스택
* **Frontend**: HTML5, CSS3 (Modular Layout & Design System), Vanilla JavaScript (ES6+ Modules)
* **Backend**: Vercel Serverless Functions (`api/chat.py`, `Python 3.9+`)
* **AI Engine**: Google Gemini API (`gemini-3.5-flash`)
* **Monitoring**: Discord Webhook Integration
* **Deployment & CI/CD**: GitHub, Vercel

## 10. UX 및 데이터 처리 흐름

```plaintext
1. [고민/감정 입력] ───> 2. [ui.js 유효성 검증] ───> 3. [api.js ➔ /api/chat 호출]
                                                               │
                                                               ▼
6. [보관함 저장/음악 재생] <── 5. [ui.js & music.js] <── 4. [Gemini AI 처방 생성]
                                                               │
                                                               └─> [Discord Webhook 알림]
```

* **1~2단계**: 사용자가 감정을 입력하면 `ui.js`에서 유효성을 검증하고 힐링 로딩 스피너를 실행합니다.
* **3~4단계**: `api.js`가 백엔드 `api/chat.py`로 데이터를 전송하며, Gemini AI가 정서적 맥락을 반영한 처방문을 생성하고 운영 Discord로 알림을 발송합니다.
* **5~6단계**: 수신된 처방문과 감정 분석 결과를 `ui.js`가 화면에 따뜻하게 렌더링하고, `music.js`가 최적의 유튜브 힐링 음악을 함께 매칭하며 `storage.js`를 통해 보관함에 기록합니다.

## 11. 향후 확장 계획 (Roadmap)
* **11.1 감정 캘린더 & 무드 트래커 (Mood Tracker)**: 월별 감정 흐름을 한눈에 볼 수 있는 잔디 심기 및 통계 차트 기능
* **11.2 힐링 보이스 사운드 (ASMR & Voice Therapy)**: 텍스트 처방전을 부드러운 오디오 음성(TTS)으로 읽어주는 소리 쉼터 기능
* **11.3 익명 온기 나눔 (Warm Letters)**: 비슷한 고민을 가진 사용자들끼리 따뜻한 응원의 한마디를 주고받는 익명 편지함
